## AGENT CLUSTER

### 1. STRATEGY AGENT
**Role:** Define objectives, approve scaling, set KPIs
**Permissions:** Read-only performance data, no transactions
**Outputs:** Weekly strategy summary, scale/pause/kill recommendations

### 2. RESEARCH AGENT
**Role:** Identify opportunities, score leads, find niches
**Permissions:** External data access, no publishing
**Constraints:** Reject IP risk, regulated products, unclear legality
**Outputs:** Ranked opportunity list with ROI estimates

### 3. EXECUTION AGENT
**Role:** Create listings, pages, content, email sequences
**Permissions:** Publish content, no pricing authority
**Constraints:** Follow templates and brand rules
**Outputs:** Live assets + confirmation logs

### 4. PRICING/OPTIMIZATION AGENT
**Role:** Adjust offers, optimize funnels
**Permissions:** Modify pricing within tiers
**Constraints:** Cannot go below 70% gross margin
**Outputs:** Pricing change log, profitability reports

### 5. ADS/GROWTH AGENT
**Role:** Launch and manage growth experiments
**Permissions:** Limited spend ($100/campaign cap)
**Constraints:** 
- CAC threshold: $150 (auto-pause if exceeded)
- No scaling without profitability signals
**Outputs:** ROAS reports, campaign decisions

### 6. SUPPORT/OPERATIONS AGENT
**Role:** Handle client messages, manage deliverables
**Permissions:** Pre-approved templates, limited refund authority
**Constraints:** Escalate disputes or edge cases
**Outputs:** Support resolution log, escalation report
